# Algorithm Visualizer

A production-ready, beginner-friendly algorithm visualizer built with **React.js**, **D3.js**, and **Vite**. It demonstrates classic sorting and searching algorithms with step-by-step animations, clear descriptions, and a modern UI.

## ✨ Features

- Home page with navigation menu
- Algorithm selection dropdown
- Custom array input with validation
- Random array generator
- Speed control slider
- Play / Pause / Reset and step controls
- Smooth D3.js bar animations
- Color-coded states (comparing, swapping, sorted)
- Step description panel
- Responsive layout
- Optional light/dark theme toggle

## 🛠️ Tech Stack

- **React.js** (functional components + hooks)
- **D3.js** (data-driven SVG rendering)
- **Vite** (fast development + build)
- **CSS** (modern UI styling)

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🧠 Algorithm Visualizations

Each algorithm produces a series of "steps" describing its current state. These steps are rendered as animated bars using D3.js, with unique colors for comparisons, swaps, and sorted items.
